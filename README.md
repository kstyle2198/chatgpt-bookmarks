# ChatGPT Learning Bookmarks v1.2

## What's New in v1.2
- Saved bookmarks are now displayed with a yellow star (★).
- Bookmarked headings now retain a light yellow background and a left-side accent border.
- A darker temporary highlight appears when navigating to a bookmarked heading from the popup.
- Fixed title text extraction to exclude the injected star button.
- Fixed bookmark state inconsistencies by using the same title extraction function for both bookmark ID generation and state restoration.

## Update Instructions
1. Open `chrome://extensions`.
2. Click the **Reload** button for the existing extension (if you have overwritten the existing extension files).
3. On the ChatGPT tab, press `Ctrl+Shift+R` to perform a hard refresh.
4. Your saved bookmarks will remain intact in Chrome's local storage.
